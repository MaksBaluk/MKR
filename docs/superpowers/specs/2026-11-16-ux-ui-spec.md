# UX/UI специфікація: профіль, результати, ринок, налаштування, перемикач профілів

Статус: проєкт для виконавця, 2026-11-16. Основа: `2026-11-16-profile-flow-design.md`, `2026-11-13-design-system.md`, `src/lib/tokens.css`. Стек без змін: React, Tailwind v4, shadcn-стиль, recharts (lazy chunk). Диплом не змінюється.

Загальні правила: тільки токени (`bg-surface`, `text-ink-muted`, `border-line`), без сирого hex у компонентах; числа `tabular-nums`; цілі дотику не менші 44x44 px; видимий фокус `ring`; жодного значення тільки кольором (завжди текст або значок); без метрик Match/Coverage/R.

## 1. Сторінка профілю (`/profile`, активний профіль)

Одна колонка, `max-w-5xl`. Порядок секцій однаковий на всіх екранах.

1. Шапка профілю + головна кнопка.
2. Основні дані.
3. Самооцінка дій (необов'язкова).
4. Шкала оцінки LLM (тільки читання).
5. Порівняння: співбесіда і самооцінка.
6. Історія спроб.

### Desktop 1366 px

```
┌ Профіль: «Frontend, Middle»  [Профіль ▾]        [Розпочати співбесіду] ┐
│ Статус: Співбесіду не пройдено · 0 спроб                                │
├───────────────────────────────┬─────────────────────────────────────────┤
│ Основні дані (Card, 2 колонки)│ Самооцінка дій (Card)                   │
│ Ім'я  [______]  Трек [▾]      │ «Необов'язково. Допомагає порівняти...» │
│ Посада [______] Досвід [__] р.│ Тема A  ──●────── 60%  [Не оцінювати]   │
│ Локація [______]  [Зберегти]  │ Тема B  ────●──── 80%                   │
├───────────────────────────────┴─────────────────────────────────────────┤
│ Оцінка LLM по темах (шкала + значення) — на всю ширину                  │
├───────────────────────────────┬─────────────────────────────────────────┤
│ Порівняння (таблиця)          │ Історія спроб (список)                  │

```
Сітка: `lg:grid-cols-[minmax(0,2fr)_minmax(0,3fr)]` для ряду «Дані / Самооцінка». Ряд «Порівняння / Історія» `lg:grid-cols-2`. Шапка sticky не потрібна.

### Mobile 375 px

Одна колонка, відступ 16 px. Головна кнопка: у шапці (повна ширина) і дублюється sticky-панеллю знизу над нижньою навігацією, тільки коли кнопка поза екраном (IntersectionObserver). Секції 2-6 як `Card`, самооцінка і порівняння згортаються (`<details>`-патерн, перша відкрита самооцінка).

### Копія (укр.)

- Заголовок: «Профіль». Підзаголовок: «Дані, самооцінка та результати співбесіди для цього профілю».
- Кнопка: стан 0 спроб: «Розпочати співбесіду»; є завершена спроба: «Пройти ще раз»; є незавершена: «Продовжити співбесіду» (вторинна «Пройти спочатку» тільки з підтвердженням).
- Основні дані: «Ім'я», «Напрям (трек)», «Бажана посада», «Роки досвіду», «Локація», кнопка «Зберегти зміни». Помилки під полем, не лише зверху.
- Самооцінка: «Самооцінка дій», пояснення «Необов'язково. Оцініть себе, щоб потім порівняти з оцінкою співбесіди. Значення зберігаються і не скидаються». До вибору треку: «Оберіть напрям, щоб оцінити дії». Слайдер 0-100, крок 5, «Не оцінювати» скидає в `null`. Автозбереження з debounce 600 мс, статус «Збережено» (`aria-live="polite"`).
- Шкала LLM до співбесіди: «Оцінка з'явиться після співбесіди». Після: заголовок «Оцінка співбесіди (LLM)», підпис «Це оцінка наданих відповідей, а не перевірений досвід».
- Порівняння до співбесіди: «Порівняння буде доступне після співбесіди».
- Історія: «Історія спроб»; рядок: «Спроба 2 · 16.11.2026 · Завершено · 11 тем», дія «Переглянути»; порожньо: «Спроб ще немає».

### Шкала оцінки LLM (read-only)

Горизонтальна смуга на тему: `<meter>`-подібний блок (div `role="img"` з `aria-label="Тема: 72%, рівень Добре"`), довжина = значення, праворуч текст `72%` і мітка рівня. Бенди (колір + мітка + значок):

| Діапазон | Мітка | Колір смуги / текст | Значок |
|---|---|---|---|
| 0.75-1 | Сильно | `success` / `success-ink` на `success-soft` | галочка |
| 0.5-0.75 | Добре | `info` / `info-ink` на `info-soft` | коло |
| 0.25-0.5 | Базово | `warning` / `warning-ink` на `warning-soft` | трикутник |
| 0-0.25 | Слабо | `danger` / `danger-ink` на `danger-soft` | хрестик |
| `null` | Немає оцінки | `line-strong`, штрих-пунктир | тире |

Під шкалою легенда з усіма п'ятьма бендами. Без слайдерного thumb і без `tabindex` (не інтерактивна).

### Порівняння (виправлення накладання, спільне з розділом 2)

Таблиця на `lg` і вище, картки на вужчих. Колонки: «Тема» (`minmax(0,1fr)`, `break-words`, `hyphens-auto`), «Співбесіда» (`7rem`, read-only, текст `72%` + мініатюра смуги), «Самооцінка» (`10rem`, слайдер + `60%`), «Різниця» (`5rem`: «+12 п.п.» зі знаком і стрілкою). На 375 px: кожна тема окрема картка, назва на всю ширину зверху, нижче два рядки «Співбесіда: 72%» та «Самооцінка» зі слайдером; жодних `auto`-колонок.

### Історія спроб

`<ol>`; поточна спроба позначена бейджем «Поточна». Кожна: номер, дата, статус (Завершено / У процесі / Перервано), кількість тем, кнопка «Переглянути результати» (для завершених). Незавершена спроба підсвічена `warning-soft`, текст «Не завершено» + значок.

## 2. Сторінка результатів (`/results`)

Доступна лише коли для активного профілю є завершена спроба. Якщо йде повторна спроба: екран-заглушка «Нова співбесіда ще не завершена» + кнопка «Продовжити співбесіду».

### Макет

Desktop (xl): `grid-cols-[minmax(0,1.4fr)_minmax(0,1fr)]`, gap 24. Ліворуч список вакансій, праворуч sticky (`top-20`, `max-h-[calc(100vh-6rem)] overflow-auto`) блок «Ваші компетентності за співбесідою». Нижче 1280 px: одна колонка, блок компетентностей над списком, згорнутий до «Показати всі».

### Картка вакансії

Ліворуч значок відсотка (`bg-primary-soft`, `text-primary`, `46x46`), підпис під ним «збіг» тільки в `sr-only` і `title` (без слів Match/Coverage). Центр: назва (`h3`), компанія, локація, режим; до 5 навичок чипами. Права колонка `sm:w-56`: кнопки «Деталі вакансії» (primary outline) і «Зберегти» за потреби.

Позначка «Не підходить» (коли провалена обов'язкова вимога): рядок на всю ширину картки вгорі, `bg-danger-soft text-danger-ink border-danger/30`, значок трикутника, текст: «Не підходить: {перший розрив}; {другий розрив}» (два перші розриви, кожен усічений до 40 символів з `title` повним текстом, якщо більше двох: «+ ще N»). Вакансія не виключається з порядку. Картка не стає сірою (щоб не втрачати контраст).

### Вкладки

`role="tablist"`: «Підходящі (N)» (збіг > 0), «Усі вакансії (M)». Дефолт «Підходящі»; якщо N = 0, автоматично «Усі» і текст «Підходящих вакансій немає. Нижче всі вакансії зі збігом 0». Лічильники з `aria-live="polite"`. Стрілки вліво/вправо між вкладками, Home/End; активація автоматична. Вибір у `?fitting=`. Мобільний 375: вкладки на всю ширину, по 50%, висота 44.

### Блок компетентностей (праворуч)

Рядок на тему: назва (`font-semibold`, `break-words`), значення + мітка бенду (як у розділі 1), причина 1-2 рядки з цитатою користувача в `<blockquote>`. Пояснення: «Це оцінка ваших відповідей, а не перевірений досвід». Низ: компактне порівняння (див. нижче) і кнопка «Редагувати самооцінку» (веде на профіль).

### Виправлення накладання «назва / значення»

Причина: `grid sm:grid-cols-[minmax(0,1fr)_auto_auto]` у вузькій правій колонці, назва і два значення з `auto` не переносяться. Рішення:

```
<li class="py-2 text-sm">
  <p class="font-semibold text-ink break-words">{name}</p>
  <dl class="mt-1 grid grid-cols-[auto_1fr] gap-x-3 gap-y-0.5 text-ink-muted">
    <dt>Співбесіда</dt><dd class="tabular-nums text-right">72%</dd>
    <dt>Самооцінка</dt><dd class="tabular-nums text-right">не оцінено</dd>
  </dl>
</li>
```
Тобто завжди двоповерхово: назва на повну ширину, нижче `dl`. Ніколи не ставити назву і значення в один рядок у колонці менше 28rem. Перевірити на 320, 375, 1024 і 1366 px; контейнер `min-w-0`.

### Стани

Завантаження: скелети карток (6 шт.), `aria-busy`. Порожньо з фільтрами: «За цими фільтрами нічого не знайдено» + «Скинути фільтри». Помилка: «Не вдалося завантажити результати» + «Спробувати ще раз». Офлайн: банер «Немає з'єднання. Показано останні збережені дані» (`role="status"`).

## 3. Сторінка ринку (`/market`)

Тільки трек активного профілю; заголовок «Профіль ринку: {трек}», підпис «Добірка з N синтетичних вакансій (джерело: примітка про дані)». Без вибору треку. Сітка: `md:grid-cols-2`, графіки 1, 5, 6 на всю ширину (`md:col-span-2`). Кожен графік = `Card` з `h2`, коротким описом, графіком (висота 288-320) і кнопкою «Показати таблицю» (перемикає на `<table>` з тими самими даними, `aria-expanded`).

Палітра кількох категорій (з токенів, послідовно): `primary`, `accent`, `warning`, `info` -> `brand-deep`, `danger` не використовувати як категорію (лише для «слабо»). Пари кольорів на гістограмах завжди з підписом даних.

| # | Графік | Тип | Вісь X / Y | Кольори | Підписи |
|---|---|---|---|---|---|
| 1 | Розподіл компетентностей | Горизонтальні стовпці (топ-15, прокрутка за кнопкою «Усі») | X: «Кількість вакансій», Y: назви | `primary`; поточна навичка кандидата `accent` | Число в кінці стовпця; позначка «У вас є» текстом |
| 2 | Рівні вакансій | Donut (Junior/Middle/Senior/Lead) | без осей | `primary`, `accent`, `warning`, `brand-deep` | Легенда зі значенням і %, у центрі «N вакансій»; рівень кандидата обведений і підписаний «Ваш рівень» |
| 3 | Формат роботи | Donut (Офіс / Гібрид / Віддалено) | без осей | `primary`, `accent`, `info` | Легенда зі значенням і % |
| 4 | Зарплатні вилки за рівнем | Діапазонні стовпці (floating bar min-max + маркер медіани) | X: «Рівень», Y: «Зарплата, грн/міс.» | вилка `primary-soft` з рамкою `primary`, медіана `brand-deep` | Підписи min/медіана/max; примітка «Лише вакансії з вказаною зарплатою (n)» |
| 5 | Обов'язкове проти бажаного | Один горизонтальний stacked-стовпець 100% | X: «Частка вимог, %» | обов'язкове `primary`, бажане `accent` | Дві підписи з % у сегментах і в легенді |
| 6 | Ваш рівень проти ринку (топ-8) | Radar, 2 серії | 8 осей = топ-8 компетентностей, шкала 0-100% | Кандидат `accent` (суцільна, заливка 20%), ринок `primary` (пунктир `4 3`) | Значки вершин різної форми (коло / квадрат) |

Радар показувати лише після завершеної співбесіди; інакше: «Радар з'явиться після співбесіди» + кнопка «До співбесіди». Графік 4: якщо n < 3 для рівня, стовпець не малюється, підпис «Замало даних».

Доступність: у кожного графіка `role="img"` + `aria-label` з коротким висновком («Найчастіше потрібні React (45) ...») і `aria-describedby` на таблицю; таблиця-альтернатива доступна без миші (кнопка «Показати таблицю», `<caption>`, `<th scope>`); тултіп також на фокус; жодного смислу лише кольором (текст, візерунок пунктиру, різні форми маркерів, значення на стовпцях); контраст ліній графіка не менш 3:1 щодо `surface`; `prefers-reduced-motion`: `isAnimationActive={false}`.

Стани: завантаження скелет за формою графіка (висота фіксована, без стрибків); порожньо: «Для цього напряму немає даних ринку»; помилка з «Спробувати ще раз»; недоступно (повторна спроба не завершена): «Профіль ринку відкриється після завершення співбесіди». Графіки 2-6 вантажаться ліниво (`React.lazy`) в окремому chunk.

## 4. Налаштування (`/settings`)

Один блок «Тема»: `role="radiogroup"` з трьох карток-радіо: «Світла», «Темна», «Системна» (значок сонця / місяця / монітора + текст + галочка вибраного; не лише колір). Дефолт «Системна». Підказка: «Системна: збігається з налаштуванням вашого пристрою».

Поведінка:
- Застосовується одразу, без кнопки «Зберегти».
- Зберігання: `localStorage['cm-theme']` = `light|dark|system`, у `try/catch` (приватний режим, помилка = тихо працюємо в пам'яті).
- Застосування: `<html data-theme="light|dark">` і `color-scheme`; для `system` слухати `matchMedia('(prefers-color-scheme: dark)')` і оновлювати без перезавантаження.
- Анти-мигання: маленький inline-скрипт у `index.html` до рендера читає `localStorage` і ставить `data-theme`.
- `<meta name="theme-color">` оновлювати відповідно.
- Анонс: `aria-live="polite"` «Тему змінено на темну».
- Перемикач також не дублювати в шапці (лише налаштування).

## 5. Перемикач профілів і створення профілю

### Перемикач (шапка AppShell, `[Профіль ▾]`)

Кнопка показує назву активного профілю (усічену, `title`) і значок. Popover (Radix `DropdownMenu`): список профілів як `menuitemradio` (активний з галочкою і `aria-checked`), підпис кожного: «Frontend, Middle · Співбесіда завершена / Не пройдено / У процесі»; внизу «Усі профілі» і «Створити профіль». Mobile: bottom sheet на всю ширину, елементи по 48 px.

Зміна профілю: оновлює контекст усього застосунку (банер незавершеної співбесіди, замки кроків, профіль, результати, ринок); залишаємося на тому ж розділі; якщо розділ недоступний для нового профілю (немає результатів) показуємо його заглушку з кнопкою до профілю. Анонс: «Активний профіль: ...».

### Створення профілю

Кнопка «Створити профіль» (шапка списку профілів і перемикач) відкриває діалог: «Назва профілю», «Напрям (трек)», «Бажана посада», «Роки досвіду», «Локація» (мінімум: назва і напрям). «Створити». Після успіху: закрити діалог, зробити профіль активним, перейти на `/profile`, фокус на `h1`, тост (`role="status"`): «Профіль створено. Заповніть самооцінку (необов'язково) і розпочніть співбесіду». Співбесіда не запускається автоматично. Помилка: текст у діалозі, кнопка залишається доступною; дублювання назв дозволено, але ліміт показується «Максимум N профілів».

### Клавіатура і скрінрідер

- Меню: Enter/Space відкриває, стрілки рухаються, Home/End, Esc закриває з поверненням фокусу на кнопку, Typeahead за назвою.
- Діалог: focus trap, `aria-labelledby`, Esc закриває, фокус повертається на ініціатор; перше поле автофокус.
- Вкладки, слайдери: стрілки (±5), Page Up/Down (±20), `aria-valuetext` «60 відсотків»; слайдер має видиму мітку.
- Skip link «Перейти до змісту» першим; одна `h1` на сторінку; landmarks `header/nav/main`; нижня навігація на mobile `aria-label="Основна навігація"`, активний пункт `aria-current="page"`.
- Зміни статусу (збереження, зміна профілю, завантаження) через `aria-live="polite"`, помилки `role="alert"`.
- Фокус завжди видимий (`focus-visible:ring-2 ring-ring ring-offset-2`), не перекривається sticky-панелями (`scroll-padding-top`/`bottom`).

### Reduced motion

`@media (prefers-reduced-motion: reduce)`: `animate-fade-up` і переходи вимкнені (`animation: none; transition: none`), графіки без анімації, плавний скрол `auto`, bottom sheet з'являється без зсуву (лише миттєве показ). Інакше: тривалість 150-240 мс, easing `--ease-standard`, анімувати лише `opacity/transform`; вихід швидше входу.

## Перевірка виконавцем

Контрольні ширини 320, 375, 768, 1024, 1366 px, обидві теми, масштаб тексту 200%, навігація лише клавіатурою, VoiceOver (мінімум Safari macOS) на профілі, вкладках результатів, таблиці-альтернативі графіка. Результати чесно записати в `docs/tasks/STATUS.md`; не заявляти успіх без запуску.
