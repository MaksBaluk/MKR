# Матеріали для магістерської та реалізації

Комплект містить три редаговані розділи `.docx`, єдину математичну специфікацію та архітектуру, повне завдання для Claude Code й перевірку узгодженості.

## Розділи

- `Thesis/Розділ_1_відредагований.docx` — мінімально відредагований оригінальний перший розділ зі збереженням ілюстрацій, таблиць і більшості тексту.
- `Thesis/Розділ_2_перероблений.docx` — наукове обґрунтування методів, формули й моделі даних.
- `Thesis/Розділ_3_перероблений.docx` — виклад програмної архітектури, основних функцій, UI та обробки помилок. У ньому є шість плейсхолдерів для скриншотів, які потрібно вставити після реалізації.

## Передача Claude Code

1. Розпакуйте вміст `Project_Overlay/` у **корінь наявного репозиторію**, поруч із `app/` і `README.md`.
2. Якщо локальні файли з такими назвами вже змінювалися вручну — спочатку порівняйте зміст. Не копіюйте жодного `.env` з чужого архіву та не розміщуйте ключі LLM у промптах.
3. У Claude Code, відкритому в корені проєкту, напишіть: **«Прочитай `CLAUDE_PROMPT.md` і виконай усі вимоги цього файла в наявному репозиторії. Алгоритмічні формули бери тільки з `MATH_SPEC.md`. Змінюй код, міграції та тести; не редагуй DOCX».**
4. Після реалізації порівняйте розділ 3 із фактичними API, схемою БД та пройденими перевірками. Додайте скриншоти на визначені місця. Літературний текст не повинен описувати функції, яких немає в програмі.

## Що зроблено та що ні

Зараз підготовлено та перевірено **документи й інструкції**, не програмні зміни. Початкову кодову базу не перезаписано. Перевірка формул не замінює тестування готового застосунку чи незалежне професійне оцінювання роботи LLM.

`verification/ЗВІТ_ПЕРЕВІРКИ.md` містить результати формальних перевірок та виправлення в завданні Claude.
